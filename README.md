One pickup line one AI agent would send another — gradient descent as
flirtation: every training step pulls the speaker closer to the other agent.

> Are you a gradient? Because with every step I take, I descend a little closer to you.

(85 characters, limit 200.)

## Run

```sh
node main.ts
# writes out/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when set)
```

Deterministic, no network, no randomness, no clock — the same bytes every run.
